# DOST-SEI Patriot Scholars Research Repository

A centralized, web-based digital library for archiving and disseminating the research outputs (theses and dissertations) of DOST-SEI scholars. Built in partnership with START – DOST, the platform follows Open Access principles so that knowledge generated by government-funded scholars remains freely accessible to the Filipino public, while safeguarding intellectual property through role-based access control, dynamic PDF watermarking, and a structured submission workflow.

## Features

- **Role-based access** — Scholar, Public User, and Administrator roles with distinct capabilities
- **Scholar verification** — Validates scholar identity against the DOST SPAS database on registration
- **Submission workflow** — Scholars submit papers (PDF, max 50 MB) with rich metadata; admins approve, return, or publish
- **Faceted search** — Filter and sort research papers by year, region, university, field of study, and keywords
- **Dynamic PDF watermarking** — Full-text downloads are watermarked with the downloader's identity and timestamp on the fly
- **Admin dashboard** — Analytics for top downloaded papers, active regions, and total research output by field
- **Email notifications** — Nodemailer-powered emails for account verification, password reset, and submission status updates
- **Data privacy** — PII encryption at rest (AES-256) in compliance with the Data Privacy Act of 2012 (RA 10173)

## Getting Started

### Prerequisites

- Node.js 20+
- A PostgreSQL database (Supabase recommended)
- An SMTP account for email (e.g. Gmail app password)

### 1. Install dependencies

```bash
npm install
```

### 2. Configure environment variables

Copy `.env.example` to `.env` and fill in the values:

```bash
cp .env.example .env
```

| Variable | Description |
|---|---|
| `DATABASE_URL` | Postgres connection string (with PgBouncer for Supabase) |
| `DIRECT_URL` | Direct Postgres connection string (used by Prisma migrations) |
| `BETTER_AUTH_SECRET` | Random 32-byte secret — generate with `openssl rand -hex 32` |
| `BETTER_AUTH_URL` | Public URL of the app (e.g. `http://localhost:3000`) |
| `NEXT_PUBLIC_APP_URL` | Same as `BETTER_AUTH_URL` |
| `ENCRYPTION_KEY` | AES-256 key (64 hex chars) — generate with `openssl rand -hex 32` |
| `SMTP_HOST` | SMTP server hostname |
| `SMTP_PORT` | SMTP server port (e.g. `587`) |
| `SMTP_SECURE` | `true` for port 465, `false` otherwise |
| `SMTP_USER` | SMTP username / email address |
| `SMTP_PASS` | SMTP password or app password |
| `SMTP_FROM` | Sender display name and address |
| `NEXT_PUBLIC_SUPABASE_URL` | Your Supabase project URL |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase service role key (keep secret) |
| `SUPABASE_STORAGE_BUCKET` | Storage bucket name for uploaded PDFs (e.g. `papers`) |

### 3. Run database migrations

```bash
npx prisma migrate deploy
```

### 4. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

```

└── schema.prisma         # Database schema
```

## User Roles

| Role | Capabilities |
|---|---|
| **Public** | Browse abstracts freely; register to download full-text PDFs |
| **Scholar** | Everything Public users can do, plus submit and manage their own papers |
| **Admin** | Review and publish/return submissions; manage users; view analytics |
